On August 11 I asked on this forum about Fortran 90/95 compilers for Dos/Win16 for a retrocomputing project.
I haven't been able so far to procure any Fortran 90 compiler for DOS, so I've used Fortran 77. 
I've written a small program to perform some preliminary benchmarks (posted at the end of this post).
This program integrates the 1-dimensional Schrodinger equation using the three-point formula for the second derivative.
There is a parameter, nitermax, which is the number of passes, and I adjust it to a value such that the runtime is easy to measure on the given system (e.g., ~10 seconds).
The output looks like this:
Finished, total_nodes =  620041
nsteps, nitermax, product =      10999     60000    0.6599E+09

The 'total_nodes' value is irrelevant, I compute it mostly to avoid compiler optimization to skip all computations altogether. The value of product (=nsteps*nitermax) is the total number of integration steps computed. 
The instructions for a single step are given by the lines between labels 40 and 41 in the code quoted at the end of this post. I then compute speed as nsteps*nitermax/time_in_seconds. 
On a relatively modern machines I get speeds of 100-300 Msteps/second (depending on compiler flags and CPU), corresponding to 10-20 CPU cycles per step. This is, I think, fairly good speed.

I then tried the same code on my 386/387 DX/40 MHz using Fortran Powerstation 1.0, and the speed was very slow, much lower than I expected. Specifically, I get 0.022 Msteps/second, corresponding to ~1800 CPU cycles per step!

I also tried the same benchmark in double precision and results are almost the same. 
Any idea why the 386 is so very slow?
I have two hypotheses:
1) The FPU is not recognized by the compiler and I'm using software emulation.
2) The lack of L1 cache in the 386/387 is killing performance

      program ThreePoint
      implicit none
      real h
      real E_trial
      real mass
      real xmin, xmax
      integer count_nodes, total_nodes
      integer   n_of_nodes, niter, nitermax, nsteps
      external function count_nodes
      
      mass = 2.0
      xmin = -5.5
      xmax = -xmin
      
c      write(*,'(1x,a)') 'Enter step size h = '
c      read(*,*) h
      h=0.001
      nsteps = int((xmax-xmin)/h)
c      write(*,'(1X,A,I10)') "Number of steps = ", 
       
      nitermax = 60000
      total_nodes = 0.
      do 20 niter = 0, nitermax
         E_trial = (1./3.) + real(20*niter)/real(nitermax)
         n_of_nodes = count_nodes(mass, xmin, xmax, h, E_trial)
         total_nodes = total_nodes + n_of_nodes
20    continue
      
      write(*,*) 'Finished, total_nodes = ', total_nodes
      write(*,'(a, I10, I10,E14.4)') 'nsteps, nitermax, product = ', 
     +            nsteps, nitermax, 
     +            real(nsteps)*real(nitermax)
      
      end
      
      function count_nodes(mass, xmin, xmax, h, E)
      implicit none
      integer count_nodes
      real xmin, xmax, h, E
      real f0, f1, f2
      real x, V, mass
      external V 
      
      x = xmin
      f0 = 0.

      x = x + h
      f1 = 0.0000001
      
      count_nodes = 0
40    continue    
        x = x + h
        f2 = 2.0*f1*(1.0-h*h*mass*(E-V(x))) - f0
        if(sign(1.0,f2).ne.sign(1.0,f1)) count_nodes=count_nodes+1
        f0 = f1
        f1 = f2
        if( x .ge. xmax) goto 41
      goto 40
41    continue
      
      end

      function V(x)
      implicit none
      real x
      real V
      
      V = x*x
      
      end
